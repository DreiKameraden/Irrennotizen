
# 📚 CodeQuest — интерактивный учебник

Учебный проект для изучения **немецкого языка, страноведения и культурологии Германии**. Курсы → уроки → интерактивные задания → прогресс. Всё работает на статике, без сервера.

---

## 🎯 Что умеет

- **Курсы и уроки** — древовидная структура, прогресс по каждому курсу.
- **5 типов уроков и блоков**:
  - 📖 **markdown** — теория (из файла или прямо в данных)
  - 🃏 **flashcards** — карточки «лицо / оборот» (лексика)
  - ✏️ **fill-blank** — вписать пропущенное слово (грамматика)
  - 🔗 **matching** — соединить пары (слова ↔ перевод)
  - 🗺️ **map** — интерактивная SVG-карта (страноведение)
  - 🎯 **hotspots** — кликабельные точки на картинке (искусство)
  - 🧠 **quiz** — вопросы с вариантами
  - 🎯 **map-quiz** — «найди землю на карте»
- **XP и достижения** — сохраняются в `localStorage`.
- **Разблокировка уроков** — урок открывается после предыдущего.
- **Блочная структура** — урок может совмещать текст, карточки, карту и квиз в любом порядке.

## 🚀 Как запустить

**Через Live Server (рекомендуется):**

1. Открыть проект в VS Code.
2. Правый клик по `index.html` → **Open with Live Server**.

**Через Python:**

```bash
python -m http.server 8000
```

Открыть `http://localhost:8000/index.html`.

> ⚠️ Просто двойной клик по `index.html` (`file://`) **не подойдёт** — `fetch` для `.md` и `.svg` не сработает.

## 🧩 Как добавить курс или урок

Всё содержимое — в **`scripts/data.js`**.

### Курс

```js
{
  id: 'course-4',
  title: 'История',
  description: 'Германия в XX веке',
  icon: '📜',
  lessons: [ /* уроки */ ]
}
```

### Урок из блоков

```js
{
  id: 'de-2-1',
  order: 1,
  xp: 50,
  title: 'Цвета',
  description: 'Учим цвета по-немецки',
  blocks: [
    { type: 'markdown', content: '## Farben' },
    { type: 'flashcards', cards: [
      { front: 'rot',   back: 'красный' },
      { front: 'blau',  back: 'синий' }
    ]},
    { type: 'quiz', questions: [
      { question: 'Как сказать «красный»?',
        options: ['rot', 'blau', 'grün'], correct: 0 }
    ]}
  ]
}
```

### Все типы блоков


| `type`       | Поля                                       | Что делает                                |
| -------------- | ------------------------------------------------ | ---------------------------------------------------- |
| `markdown`   | `content` или `file`                        | Текст.`file` грузит `lessons/<file>.md` |
| `flashcards` | `cards: [{front, back}]`                       | Карточки                                   |
| `fill-blank` | `items: [{text, answer}]`                      | `___` в тексте = пропуск             |
| `matching`   | `pairs: [{left, right}]`                       | Соединить пары                        |
| `hotspots`   | `image, points: [{x, y, title, text}]`         | Точки на картинке                   |
| `map`        | `map: 'germany', lands: {ID: {name, capital}}` | SVG-карта                                     |
| `map-quiz`   | `map, targets: [ID...], lands`                 | «Найди землю»                          |
| `quiz`       | `questions: [{question, options, correct}]`    | Вопросы                                     |

## 🗺️ Как добавить новую карту

1. Положить SVG в `maps/<имя>.svg`.
2. У каждой области должен быть **`id`** (например, `DEBY`) и **`class`** или просто `<path id="...">`.
3. В `data.js` создать блок:

```js
{
  type: 'map',
  map: 'austria',
  lands: {
    AT1: { name: 'Бургенланд', capital: 'Айзенштадт' },
    AT2: { name: 'Каринтия',   capital: 'Клагенфурт' }
  }
}
```

**`map.js` универсальный** — для новой карты его править не надо.

## 🧠 Как работает прогресс

- Хранится в `localStorage` под ключом `progress`:
  ```json
  { "completed": ["de-1-1"], "xp": 40, "achievements": ["first"] }
  ```
- Урок считается пройденным, когда нажата кнопка **«Завершить урок»**.
- Кнопка появляется:
  - сразу — если в уроке нет `quiz` / `map-quiz`;
  - после правильных ответов — если есть.
- Достижения: `first` (1 урок), `three` (3 урока), `all` (5 уроков).

## 🌐 Деплой на GitHub Pages

1. Создать **публичный** репозиторий.
2. Загрузить все файлы (`index.html`, `scripts/`, `lessons/`, `maps/`, `images/`).
3. Settings → **Pages** → Source: `main`, папка `/ (root)`.
4. Через минуту сайт будет доступен: `https://<username>.github.io/<repo>/`.

**Важно:**

- Все пути **относительные** (`scripts/site.js`, `lessons/lesson-1-1.md`).
- **Не использовать** `fetch('https://raw.githubusercontent.com/...')` — CORS не даст.
- Добавить файл `.nojekyll` в корень (пустой) — чтобы GitHub не трогал файлы с `_` в имени.

---

## ⚠️ Известные ограничения

- Tailwind через CDN ругается в консоли: *«should not be used in production»*. Для учебного проекта — нормально. Для продакшена — собрать через npm.
- Прогресс хранится **только в браузере** пользователя. Между устройствами не синхронизируется (для этого нужен бэкенд — Firebase, Supabase и т.п.).
- Markdown-файлы и SVG не грузятся через `file://` — нужен локальный сервер или GitHub Pages.
