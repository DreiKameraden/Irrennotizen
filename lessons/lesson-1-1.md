# Переменные

Переменная — это **именованный контейнер** для хранения данных.

## Объявление

```javascript
let age = 25;        // можно изменять
const name = "Аня";  // нельзя изменять
var old = true;      // устаревший способ
```

## Типы данных

```javascript
let number = 42;           // число
let text = "Привет";       // строка
let flag = true;           // булево
```

## Итог

- `let` — для изменяемых
- `const` — для констант
- `var` — не используйте
