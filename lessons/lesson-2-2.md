# Условия

Программы принимают решения с помощью `if`.

## if / else

```javascript
if (age >= 18) {
  console.log("Взрослый");
} else {
  console.log("Ребёнок");
}
```

## Операторы

- `===` строго равно
- `!==` строго не равно
- `>` больше, `<` меньше
- `&&` И, `||` ИЛИ, `!` НЕ

## Тернарный оператор

```javascript
let status = age >= 18 ? "взрослый" : "ребёнок";
```

## Итог

- Используйте `===` вместо `==`
- `if / else if / else` — основная конструкция
